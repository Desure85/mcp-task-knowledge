## Вопрос

Закрыть непокрытые части T-05: шаблоны документов, запись ревью, список устаревших документов.

## Решение

- `knowledge_template_list` — `DATA_DIR/knowledge-templates/*.md`.
- `knowledge_template_apply` — подстановка `{{title}}`, `{{project}}`, `{{date}}`; возвращает markdown, не создаёт документ.
- `knowledge_review` — `reviewedBy/reviewedAt`, опционально `status=published`.
- `knowledge_stale` — документы старше N дней (default 90), сортировка по `updatedAt`.
- В `KnowledgeDocMeta` добавлены `reviewedBy?`, `reviewedAt?`.

## Почему

- Шаблон — обычный markdown-файл; не нужна новая схема.
- Apply отделён от create: человек видит результат до записи.
- Stale считается по `updatedAt`, без отдельного индекса.

- Нет UI для шаблонов/ревью/stale.
