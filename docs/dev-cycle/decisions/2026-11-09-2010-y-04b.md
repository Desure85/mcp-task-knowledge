## Вопрос

Нужен реальный HTTP-провайдер для внешних эмбеддингов — но он не должен сам решать вопросы
egress: флаг, ключи, лимиты и стоимость уже живут в обёртке Y-04a. Требования ADR: ошибка
провайдера — признак деградации, а не «ничего не найдено»; таймауты и ретраи обязательны.

## Решение

1. **`src/search/external-http-provider.ts`** — OpenAI-совместимый провайдер:
   `POST {baseUrl}/embeddings` с `Authorization: Bearer <key>`; батчи по `maxTextsPerRequest`
   (по умолчанию 64); таймаут на запрос (по умолчанию 10 с, `AbortController`); ретраи на
   429/5xx/сетевые ошибки (по умолчанию 2, с backoff); строгая проверка ответа — число векторов,
   непустые и конечные значения, неизменная размерность между батчами. Ошибки бросаются, а не
   превращаются в пустой список.
2. **Обёртка Y-04a получила `createInner(secret)`**: внутренний провайдер создаётся **только
   после** резолва секрета, а при выключенном флаге не создаётся вообще. Это держит ключ вне
   конструктора статуса и сохраняет правило «без флага внешних вызовов нет» на уровне объекта.
3. **Выбор провайдера в `createServerContext()`**: при `EMBEDDINGS_EXTERNAL_ENABLED=1` профиль
   получает обёртку вокруг HTTP-провайдера (SecretManager + гейт Y-04a); при
   неполной конфигурации (`externalEmbeddingConfigProblem`) — предупреждение в лог и `undefined`
   вместо провайдера, а не молчаливый сбой. По умолчанию путь локальный (ONNX через
   `ensureVectorAdapter`), поведение не менялось.
4. **Признак деградации:** ошибка HTTP (после ретраев) → `PROVIDER_ERROR` из обёртки + событие
   `onEvent` (в лог — без секрета). Пустой результат не подменяет ошибку.
5. **Стоимость** считается обёрткой по фактически отправленным текстам (оценка токенов) — HTTP
   слой только возвращает векторы.

## Почему

- HTTP-слой без политики: иначе флаг/ключи/лимиты пришлось бы дублировать в двух местах, и
  «выключено по умолчанию» перестало бы быть проверяемым одним условием.
- Ленивый `createInner`: единственный способ не держать ключ в состоянии провайдера до первого
  реального вызова и не создавать HTTP-клиент при выключенной функции.
