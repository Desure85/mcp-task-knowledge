## Вопрос

Сделать `dashboard_*` настраиваемыми виджетами: список по запросу, burndown, распределение по полю,
затраченное время; раскладка — на пользователя.

## Решение

- `WidgetConfig {id,type,title?,query?,field?,days?,limit?}`; типы `list|distribution|burndown|time`;
  ≤20 виджетов, уникальные id, валидация query через TK-02.
- `dashboard-widgets.json`: `Record<user, {widgets,updatedAt}>`; user = session id (или явный `user`).
- Tools: `dashboard_widgets_get/set/render`.
- `render`: list (query), distribution (status/priority/type/tag/assignee), burndown (N дней по createdAt/updatedAt).
- `time` честно возвращает `supported:false` до TK-05 work items.

## Почему

- Раскладка — простой JSON, без миграции схемы.
- Burndown без `closedAt` в wire считается приближённо по `updatedAt` для done-задач; это записано в ответе.
- `time` не имитируется: затраченное время появится с work items.

- Burndown приближённый: `done` по `updatedAt`, не по дате закрытия.
- Distribution по custom fields недоступен (TK-01 storage ещё не реализован).
- `time` не поддерживается до TK-05.
