# 2026-11-13 04:30 — UI-29: типизированные связи в графе знаний

- **Пункт:** UI-29 (medium); зависимость UI-28

## Вопрос

Факт — свободный текст плюс список сущностей; рёбер «A использует B» нет. Как добавить
subject–predicate–object, не сломав старые факты и API?

## Решение

Сервер:

- `src/memory/relations.ts`: allowlist 12 предикатов, `normalizeRelations` — trim, dedupe по
  `subject|predicate|object`, запрет пустых и self-relation; ошибки `RelationError`.
- `TemporalFact.relations` + `AddFactInput.relations`; `addFact` нормализует поле.
- `memory_temporal_add` принимает `relations` (Zod enum по allowlist, max 100); query/history
  отдают поле как есть.
- Миграция: при `load()` отсутствующее поле становится `[]`; старый `temporal-graph.json`
  читается без изменений, запись сохраняет новый массив.

UI (`/graph`):

- третий режим `Relations` (`GraphMode`), узлы — сущности, directed edges subject→object,
  predicate как подпись ребра;
- повторяющиеся тройки схлопываются с весом (толщина), чипы фильтра по predicate;
- режим запоминается в `localStorage` (`graph.mode`); легенда/панель объясняют третий режим.

## Почему

- Allowlist не даёт превратить граф в произвольные строки и сохраняет предсказуемость UI.
- Dedupe на входе убирает дубли из повторного извлечения.
- `[]`-миграция — additive: старые факты и старые клиенты не ломаются.
- Отдельный режим не смешивает co-occurrence и типизированные рёбра.

## Ограничения

- `memory_extract` не извлекает отношения из свободного текста — только явный вход.
- Нет `memory_temporal_update`; relations фиксируются при добавлении факта.
- Валидация predicate — фиксированный allowlist, расширение только кодом.
- UI показывает только загруженные страницей факты; на 390 px таблица узлов шире экрана
  (горизонтальный скролл контейнера, не page overflow).
- Скриншоты сняты на синтетическом `DATA_DIR` (4 факта), не на данных владельца.

## Откат

Убрать `relations` из типов/`addFact`/схемы, удалить `relations.ts`, тесты, режим `Relations`
и документацию; старые данные продолжат читаться (поле additive).
