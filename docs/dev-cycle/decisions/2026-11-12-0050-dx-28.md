## Вопрос

`CONTRIBUTING.md` уже был, но не было PR/issue-шаблонов и devcontainer, а в
`docs/architecture.md` не было отметки, когда диаграмма последний раз сверялась с кодом.

## Решение

- `.github/PULL_REQUEST_TEMPLATE.md`: BACKLOG-пункт, Session ID, обязательные проверки
  (build/lint/test/backlog/mutation), честный раздел «не сделано».
- `.github/ISSUE_TEMPLATE/{bug_report,feature_request}.md`.
- `.devcontainer/devcontainer.json`: Node 24, `npm ci && npm run build`, `EMBEDDINGS_MODE=none`.
- `docs/architecture.md`: Last verified + перечень сверенных модулей; явно оговорено, что
  auth-gate/SecurityStack/project ACL не показаны на диаграмме, а описаны в security/ADR.

## Почему

- Шаблоны уменьшают долю PR без проверок и без ссылки на BACKLOG.
- Devcontainer даёт одинаковый Node 24/ESM baseline без установки глобальных пакетов.
- Отметка Last verified делает устаревание диаграммы видимым, не переписывая её целиком.

## Проверено

- `markdownlint` для новых/изменённых markdown-файлов.
- `npm run docs:test` — executable-docs для README/docs (в CI).
- backlog:check **365/33**.
- Мутация не применима: только документация/конфигурация dev-среды; CI validate это проверяет.

## Ограничения

- Devcontainer не собран в этой среде (Docker недоступен); конфиг минимальный и не заменяет
  локальную установку.
- `docs/architecture.md` по-прежнему опускает per-request middleware; это осознанное упрощение.
- Шаблоны не автоматизируют проверки, только напоминают.

## Откат

Удалить новые шаблоны/devcontainer и блок Last verified; CONTRIBUTING.md не менялся.
