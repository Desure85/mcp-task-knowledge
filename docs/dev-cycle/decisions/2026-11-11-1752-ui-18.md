# 2026-11-11 17:52 — UI-18: Analytics trends and activity

## Вопрос

`/analytics` показывал только текущие счётчики (`dashboard_stats`) и локальные feedback-записи. Не было
графика создания/закрытия за период, ленты `dashboard_activity`, переключателя day/week, периода и
осмысленного пустого состояния.

## Решение

- `loadStats` теперь одним `Promise.allSettled` запрашивает `dashboard_stats`, `dashboard_trends({days,
  granularity})` и `dashboard_activity({limit:12})`; stats остаются с прежним fallback на `tasks_list`.
- Блок периода: `Daily/Weekly` (`aria-pressed`) и `7d/30d/90d`; смена перезапрашивает `dashboard_trends`.
- `TrendChart`: CSS-бары created/completed по бакетам, максимум по данным, подписи дат через шаг, легенда,
  `role="img"` с текстом «N created, M completed over D days».
- `ActivityFeed`: `role="list"` (12 последних), тип `Badge`, заголовок, действие и дата; пусто — `EmptyState`
  с кнопкой «Create a task».
- Пустой проект (`stats.totalTasks === 0`): `EmptyState` «No analytics yet» с объяснением и кнопкой
  «Create a task» → `/tasks`.
- Только существующие примитивы (`Button`, `Card`, `Badge`, `EmptyState`, `Skeleton`), семантические токены;
  DESIGN.md не менялся.

## Почему

- `dashboard_trends`/`dashboard_activity` уже были в API и клиенте (UI-10), мёртвых вызовов не добавляем.
- Один параллельный запрос вместо последовательных: страница не ждёт каждый график по очереди.
- CSS-бары вместо библиотеки графиков: нет новой зависимости, те же токены и плотность; подписи дат
  прорежены, иначе 30 подписей нечитаемы.
- Empty state по `totalTasks=0`: это единственный сигнал, который уже есть в `dashboard_stats`; отдельный
  запрос «есть ли документы» не нужен.

## Ограничения

- График — CSS-бары без оси Y, tooltip только `title`; нет hover-подписей/точек.
- Лента ограничена 12 событиями; «календарь» периодов 7/30/90, произвольный диапазон не задаётся.
- Период и granularity не сохраняются между reload (state component-only).
- `dashboard_stats` считает `totalTasks` без archived/trashed, но с пустым docs-проектом страница всё равно
  покажет «No analytics yet»; отдельного docs-only состояния нет.
- E2E чистит все задачи текущего проекта (trash), чтобы проверить empty state; это безопасно на выделенном
  DATA_DIR, но не для демо-данных.
- Baseline-скриншоты не добавлялись; page-contract сравнивает только шапку.
