## Вопрос

Как гарантировать, что импортированный плагин не получает доверие, скрипты/hooks/`.mcp.json` не
включаются сами, сеть не используется без запроса, а отсутствие лицензии видно?

## Решение

- `src/skills/plugin-security.ts`:
  - каждый файл пакета получает `trustLevel: 'external'` и `enabled: false` — доверие не выводится
    из имени или расположения;
  - `inspectPluginSecurity(pkg)` явно перечисляет `hooks`, `mcpConfig`, `executableFiles`,
    `networkFiles` (URL/fetch/axios/net.connect/WebSocket), лицензию (`plugin.json.license` или
    `LICENSE`/`LICENCE`/`COPYING`) и предупреждения `LICENSE_MISSING`/`LICENSE_UNDECLARED`/
    `EXECUTABLES_PRESENT`/`NETWORK_REFERENCES_PRESENT`;
  - `activatePluginPackage(pkg, request)` по умолчанию не включает **ничего**; включение компонента
    требует `enableComponents`, hooks — `allowHooks`, `.mcp.json` — `allowMcp`, компонент со
    скриптами — `allowScripts`; сеть — только `allowNetwork: true` (флаг отражает факт ссылок).
  - `PluginSecurityError` с кодами `ACTIVATION_DENIED`/`UNKNOWN_COMPONENT`/`NETWORK_NOT_ALLOWED`.
- `PluginManifest.license` добавлен в парсер Z-02 (optional); путь лицензии ищется по файлам.
- Экспорт из `src/skills/index.ts`; MCP-инструменты и UI не менялись.

## Почему

- Deny-by-default и именованные разрешения — единственный способ не превратить «просто посмотрел
  пакет» в исполнение чужого hook; флаг компонента и флаг разрешения разделены.
- `trustLevel: external` на каждом файле — тот же уровень, что у веб-контента, и совместим с
  egress-сканером; это не ослабляет существующие проверки.
- Лицензия — не блокер импорта, но предупреждение обязательно: отсутствие лицензии не должно
  выглядеть как разрешение.

## Проверено

- `tests/plugin-security.test.ts` — **5/5**: все файлы external/disabled; hooks/mcp/скрипты/сеть/
  лицензия видны; default activation пуст; hooks без `allowHooks` → `ACTIVATION_DENIED`, с флагом
  включаются; `allowScripts`/`allowMcp` обязательны; сеть выключена без `allowNetwork`; отсутствие
  лицензии даёт `LICENSE_MISSING` и текст предупреждения.
- **3 мутации RED**: trustLevel не external (1), hooks включены по умолчанию (1), сеть всегда
  включена (2).
- build/tsc чистые; eslint/markdownlint — в PR.

## Ограничения, записанные честно

- Это модель и API проверки/активации, а не песочница исполнения: если внешний код всё же запустят,
  изоляции процессов/сети здесь нет — это Z-03/инфраструктура.
- `networkFiles` — эвристика по текстовым файлам до 256 KiB; бинарные/огромные файлы не сканируются.
- UI-показ компонентов и XSS-безопасный рендер — Z-03; MCP-инструмент инспекции не добавлен.
- `plugin.json.license` и файл лицензии не сверяются по тексту; `LICENSE_UNDECLARED` — мягкое
  предупреждение.
