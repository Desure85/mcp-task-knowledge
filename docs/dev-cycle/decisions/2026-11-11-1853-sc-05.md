# 2026-11-11 18:53 — SC-05: LOD, окрестность и кластеризация графа

- **Пункт:** SC-05 (medium)
- **Ветка / sha:** `feat/sc-05-graph-lod`, от `origin/master` `94139a6`

## Вопрос

`generateGraphHTML` рисовал все узлы SVG и гонял O(n²) force-симуляцию на каждом кадре:
1000 узлов ≈2.3 с и ~2 с Long Tasks, 5000 — 13.7 с и 16.3 с. Не было лимита, окрестности,
кластеризации и легенды «показано N из M».

## Решение

- Жёсткий cap **300** узлов (сортировка по degree, tie по id); stats:
  `Showing N of M nodes / E edges`.
- Для >30 узлов — детерминированная раскладка по 4 кольцам и **один** рендер; force-симуляция
  остаётся только для малых графов. `tick()` и `requestAnimationFrame` сохранены для малых.
- Подписи — только top-18 по degree (+кластеры/фокус) с простой проверкой пересечения боксов;
  в плотном виде рёбра тоньше и прозрачнее.
- `Cluster: type` / `Cluster: tag` — агрегирующие узлы с count; клик по кластеру раскрывает его
  (`expanded` Set), повторная агрегация пересобирает рёбра с weight.
- `Neighborhood: 1/2` — клик по узлу задаёт `focusId`, BFS по `fullAdj` оставляет узлы в радиусе
  depth; stats показывает `depth d around <id>`.
- `Regenerate` не добавлялся: HTML самодостаточен.

## Почему

- Cap 300 даёт предсказуемую стоимость при любом входе; «показано N из M» честно говорит, что
  граф усечён.
- Статическая раскладка для больших графов убирает 160 кадров перерисовки — основной источник
  Long Tasks; малые графы остаются живыми.
- Кластеры и окрестность решают реальные задачи на больших графах (обзор/локальный контекст) без
  нового серверного формата: всё считается в сгенерированном HTML.
- Подписи top-degree соответствуют «только у крупных узлов»; collision pass не даёт им слипнуться.

## Ограничения

- Синтетический ring/star-граф, не реальная память; распределение degree другое.
- Один Windows-хост, headless Chromium; бенчмарк не CI-гейт.
- Лимит по числу узлов, не по числу рёбер: плотные 300 узлов могут быть тяжелее.
- Ширина подписи приблизительная (длина строки), не измеренные глифы.
- `Cluster: tag` группирует по **первому** тегу; multi-tag узел попадает в одну группу.
- При depth>0 и смене фокуса позиции пересчитываются; анимации перехода нет.
- Поиск/фильтр работают по видимому (cap/neighborhood) набору, а не по всем узлам.
