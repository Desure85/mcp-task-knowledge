## Вопрос

Доска = сохранённый запрос, а не жёсткие 4 колонки; колонки/дорожки по полю; спринты со сроками.

## Решение

- `BoardConfig {project,query?,columns[{id,title,query}],swimlaneField?}`; 1..20 колонок, query через TK-02.
- `tasks_board`: базовый query → колонки по query; swimlane-счётчики по type/priority/assignee/tag;
  fallback — по одной колонке на встречающийся статус.
- Sprints: `project_sprint_list/save/delete` с проверкой дат; `tasks_sprint_assign` (null очищает).
- `Task.sprintId?: string | null`.

## Почему

- Доска не привязана к фиксированным статусам: каждая колонка — запрос.
- Спринты отдельным файлом, без миграции; назначение — обычный patch задачи.
