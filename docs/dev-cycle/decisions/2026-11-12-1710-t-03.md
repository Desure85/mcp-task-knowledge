## Вопрос

Показать админу, кто/когда/что вызвал, с фильтрами и страницами, не раскрывая чувствительные поля.

## Решение

- Новый MCP tool `admin_audit_query` (admin-only) поверх `AuditLogger.query`: userId/target/status/since/until/limit/offset.
- `ServerContext.auditLogger` выставляется AppContainer.
- `web-ui`: `api.system.auditQuery`, карточка Audit log на `/system` — фильтры user/tool/result, таблица, Previous/Next.
- Redaction остаётся в `AuditLogger`.

## Почему

- Переиспользуется существующий audit logger и admin-role gate из session tools.
- UI читает через MCP, как остальные system-виджеты, без нового HTTP-роута.

## Проверено

- `tests/session-tools.test.ts` — **19/19**, включая admin/denied и query.
- web-ui `tsc --noEmit`; design guards + no-hardcoded-colors **12/12**.

## Ограничения

- `project` фильтруется после `AuditLogger.query`, поэтому `total` при project-фильтре — число совпадений на странице, не глобальное.
- Нет ссылки на запись git-истории: audit event не содержит commit hash.
- Отдельного e2e/компонентного теста UI нет.

## Откат

Удалить `admin_audit_query`, поле `ctx.auditLogger`, карточку Audit log и метод `api.system.auditQuery`.
