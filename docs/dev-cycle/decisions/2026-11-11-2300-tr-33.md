# 2026-11-11 23:00 — TR-33: fetch timeouts на всех коннекторах

- **Пункт:** TR-33 (medium)
- **Ветка / sha:** `feat/tr-33-connector-timeouts`, от `origin/master` `4e9e0c3`
- **Сырьё:** `src/connectors/{github,jira,slack,gdrive,gmail,notion,onedrive,linear}.ts`

## Вопрос

Как не дать зависшему внешнему API пиновать MCP tool call на минуты, если восемь коннекторов
используют bare `fetch` без сигнала таймаута?

## Решение

- Добавлен `src/connectors/fetch-timeout.ts`:
  - `DEFAULT_CONNECTOR_TIMEOUT_MS = 10_000`;
  - `connectorTimeoutFromEnv()` читает положительный `CONNECTOR_TIMEOUT_MS`, иначе дефолт;
  - `connectorSignal()` возвращает `AbortSignal.timeout(...)`.
- Все восемь коннекторов передают сигнал:
  - module-level `fetch` — github, jira, slack;
  - приватные `doFetch`/GraphQL/Notion wrappers — gdrive, gmail, onedrive, notion, linear.
- `web-crawler` уже имел собственный timeout и не менялся.
- Wire-формат и параметры инструментов не менялись; таймаут общий, env-настройка.

## Почему

- `AbortSignal.timeout` — штатный undici/Node механизм, не требует таймеров и гонок.
- Один helper исключает девять разных реализаций и даёт единый дефолт; env позволяет
  поднять таймаут для медленных self-hosted инсталляций.
- Ошибка `AbortError` остаётся обычной ошибкой tool call; коннекторы не глотают её молча.

## Проверено

- `tests/connector-timeouts.test.ts` — **2/2**: дефолт 10 с, env 2500/0/`wat`, `AbortSignal`
  и контракт «каждый из 8 файлов содержит `connectorSignal(`».
- `tests/new-connectors.spec.ts` — 21/21 без регрессий.
- tsc/build зелёные.
- **Мутация RED:** удаление `signal: connectorSignal()` из github.ts роняет контрактный тест
  (missing `github.ts`).

## Ограничения

- Таймаут один на запрос; отдельного connect/read бюджета нет.
- Env читается при каждом запросе (не кешируется) — это осознанно для тестов/переопределения.
- `connectorSignal()` не отменяет уже начатый fetch при ошибке вызывающего кода; это только
  собственный deadline запроса.
- На Windows некоторые сторонние тесты коннекторов по-прежнему зависят от сети; этот тест
  герметичен и сеть не использует.

## Откат

Revert ветки: удаляется helper, сигналы из коннекторов и контрактный тест; коннекторы снова
используют bare fetch. Формат ответов не меняется.
