# 2026-11-11 21:00 — UI-17: Overview «что требует внимания»

- **Пункт:** UI-17 (high); зависит от UI-10 и U-01 (закрыты)
- **Ветка / sha:** `feat/ui-17-overview-attention`, от `origin/master` `46e904c`
- **Сырьё:** `dashboard_stats`, `dashboard_activity`, `tasks_list`, `knowledge_list`

## Вопрос

Как превратить `/` из сетки карточек-дублей меню в обзор того, что требует внимания, и при этом
показывать KNOWLEDGE N вместе с числом тегов из одного источника?

## Решение

- Удалена прежняя сетка `NAV_SECTIONS` (дублировала боковое меню). Вместо неё —
  `OverviewAttention`:
  - **Blocked tasks** — `tasks_list`, статус `blocked`, ссылки на задачи;
  - **Claimed tasks** — задачи с неистёкшим `claim.expiresAt`;
  - **Stale documents** — документы без обновления ≥90 дней, ссылки в reader;
  - **Recent activity** — `dashboard_activity` (8 записей) после правок задач/документов;
  - у каждого блока пустое состояние с действием/ссылкой.
- **KNOWLEDGE N и теги** берутся из одного `dashboard_stats`: нижняя строка
  `${knowledge.total} documents · ${tags.unique} unique tags · ${tasks.blocked} blocked as reported by
  dashboard_stats`, а плитка Knowledge использует те же поля. Один запрос, один объект.
- **Найден и исправлен профильный баг:** `dashboard_stats` и `dashboard_activity` читали файловые
  `listTasks`/`listDocs` напрямую, поэтому на SQLite-профиле отдавали нули. Оба инструмента
  переведены на `storageProfile(ctx).tasks/docs.list`; `dashboard_trends` и остальные чтения не
  тронуты. Формат ответа не менялся.

## Почему

- Уже существующие `dashboard_activity` и `tasks_list` дают ленту и блокировки без нового
  серверного формата.
- «Ближайшие сроки» из описания пункта невозможны: поля deadline нет (TK-01). Виджет не
  имитируется; остальные четыре — реальные. Это записанное ограничение, а не выданная работа.
- Исправление профиля обязательно: иначе обзор на SQLite-демо показывает 0 при существующих данных;
  это не связано с UI-17 логически, но обнаружено его e2e.

## Проверено

- `e2e/overview-attention.spec.ts` — **1/1**: создаются blocked task, обычная задача и документ с
  тегом; `/` показывает blocked-ссылку, empty claim, Recent activity с задачей и документом, строку
  `N documents · M unique tags · K blocked…`; старой карточки `Knowledge base` нет.
- web tsc; design guards; существующие Overview/страницы не ломаются.
- **RED до фикса профиля:** e2e видел `0 documents · 0 unique tags` и «No recent changes», хотя
  blocked-задача из `tasks_list` отображалась; после перевода dashboard на `storageProfile` — зелёный.

## Ограничения

- Виджет «ближайшие сроки» отсутствует: у задачи нет deadline (TK-01). Не выдаётся за сделанный.
- Stale-порог фиксирован 90 дней; настройки нет.
- Activity — последние 8 записей, сортировка по `updatedAt`; это не audit-log.
- Overview делает 4 параллельных вызова (stats/tasks/docs/activity), без кеша.
- `dashboard_trends`/`project_summary` по-прежнему читают файловый store; в этот пункт не входят и
  отдельно не исправлялись.

## Откат

Revert ветки: возвращается сетка `NAV_SECTIONS`, удаляется `OverviewAttention`, dashboard-инструменты
снова читают файловые listTasks/listDocs. Формат ответов и схема не меняются.
