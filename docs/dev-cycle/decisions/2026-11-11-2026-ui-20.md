## Вопрос

На 390×844 горизонтальная полоса из 10 nav-пунктов занимала всю ширину, цели нажатия были
28–32 px, PageHeader уезжал при скролле, а таблица задач имела `min-w-[720px]`. Нужен мобильный
шелл и контракт: меню открывается/закрывается, активный раздел виден, все цели ≥44 px, overflow 0
на 12 маршрутах, основное действие закреплено.

## Решение

- `MobileNav` (Sidebar.tsx): вместо полосы — компактная строка «активный раздел + Menu».
  Menu открывает `Dialog` с секциями NAV_SECTIONS, `aria-current="page"` у активного, ссылки
  `min-h-11`, Close; закрывается по ссылке/Escape/overlay (Dialog), закрывается при смене pathname.
- Topbar на `<sm`: Realtime, Auth и Sign out скрыты (они доступны на /access и на широком экране);
  остаются title и ThemeSwitcher. Это убирает переполнение 390.
- `PageHeader` на `<lg`: sticky под topbar+mobile-nav, с фоном/blur и нижней границей — «New task»
  и другие основные действия остаются видны при скролле.
- `globals.css` (`max-width:1023px`):
  - `main a[href]`, `button`, `input/select/textarea` (кроме `sr-only`/hidden) — min 44 px,
  - `main a[href]` — inline-flex для высоты 44,
  - `body overflow-x: hidden`, media `max-width:100%`;
  - `table[data-mobile-cards]` — карточка на строку: thead скрыт, tr = bordered card, td =
    block, `td[data-label]::before` подпись. Применено к списку задач (`app/tasks/page.tsx`),
    добавлены `data-label="Task|Status|Priority|Tags"`.
- `--spacing-mobile-nav: 56px`.

## Почему

- Drawer вместо двух строк иконок даёт полноценные 44px-цели и не конкурирует за ширину.
- Глобальный 44px-контракт в media-query — единственный способ покрыть все страницы, включая
  сторонние кнопки/инпуты; `sr-only` радиокнопки исключены (их кликабельный label — цель).
- Sticky PageHeader закрепляет primary action без отдельного portal/панели.
- Карточки на CSS с `data-label` не дублируют JSX и работают для вложенных строк.

## Ограничения

- В карточки переведена таблица списка задач; остальные плотные таблицы (settings/system) остаются
  горизонтально прокручиваемыми внутри wrapper, без потери страничного overflow.
- Глобальный `min-width:44` для input/select меняет плотность форм на мобильном.
- Topbar на мобильном не показывает realtime/auth/signout; они доступны на /access и desktop.
- Sticky PageHeader занимает ~104 px сверху; на низких экранах меньше контента.
- Кнопка Menu не имеет иконки-гамбургера (текст «Menu»); доступность сохранена.
- Внешние/встроенные iframe и canvas-интеракции не проверялись на 44px.
- Скриншоты сняты локально Chromium 1193; CI screenshot-контракт только header.

## Откат

Вернуть прежний MobileNav и Topbar, убрать sticky/44px CSS и `data-mobile-cards`; e2e mobile удалить.
