## Вопрос

Wiki-ссылки `[[…]]`, обратные ссылки, статусы «черновик → опубликовано».

## Решение

- `src/knowledge/wiki.ts`: `parseWikiLinks`, `resolveWikiTarget` (id/title/slug), `buildBacklinks`.
- Tools: `knowledge_backlinks`, `knowledge_wikilinks`, `knowledge_publish`.
- `KnowledgeDocMeta.status?: 'draft' | 'published'`; `createDoc` принимает `status` (default published).

## Почему

- Ссылки не меняют формат markdown: `[[Target|label]]` разбирается при чтении, отдельный индекс не нужен.
- Backlinks считаются по всем документам проекта; для малых баз это достаточно.
