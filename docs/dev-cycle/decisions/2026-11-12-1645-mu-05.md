## Вопрос

Показать в UI ленту изменений задачи, дифф и восстановление версии; при `CONFLICT` дать выбор
«взять чужое / оставить моё / слить».

## Решение

- `api.tasks.history/diff/versionRestore` → MCP `tasks_history/diff/version_restore`.
- В карточке History на `/tasks/[id]`: кнопка Show history, список коммитов (hash/subject), Diff и Restore.
- `save()` отправляет `expectedVersion = task.version`; при `CONFLICT` открывается Dialog с версиями и
  списком конфликтующих полей:
  - **Take current** — перечитывает задачу и заменяет локальные поля;
  - **Keep mine** — повторяет save с `currentVersion`;
  - **Merge manually** — закрывает диалог, пользователь правит поля вручную (без автоматического merge).
- `Task.version?: number` добавлен в web-ui тип.

## Почему

- Переиспользует MU-04 tools и MU-02 версию, без нового wire-формата.
- Restore — отдельный коммит на сервере; UI только перечитывает задачу.
- Ручной merge честнее автоматического: field-level merge без UI-выбора полей был бы скрытым.

## Ограничения

- History UI только для задач; knowledge/skills UI не добавлены.
- «Merge manually» не выполняет автоматический field-level merge; это ручное редактирование.
- Нет отдельного e2e/компонентного теста; проверены типы и стражи.
- История доступна только при `HISTORY_ENABLED=1`; иначе список пуст с подсказкой.

## Откат

Убрать карточку History, Dialog conflict, методы `api.tasks.history/diff/versionRestore` и `Task.version`.
