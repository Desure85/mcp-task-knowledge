# 2026-11-14 08:35 — CM-03b: Claude Code / OpenCode visibility of `instructions`

- **Пункт:** CM-03b (high, был `blocked`)

- **Связано:** CM-03a (протокол), CM-04 (режимы моста), CM-06 (проектный скилл)

## Вопрос

Показывают ли реальные CLI-клиенты `instructions` из MCP `initialize` в чистой сессии без
проектного скилла — и пересказывает ли агент хотя бы два шага?

## Решение

| Клиент | Версия | MCP-сервер | Результат |
|---|---|---|---|
| Claude Code | 2.1.325 | локальный `dist/index.js`, `--strict-mcp-config` | **видит**: дословно выдал шаги 1–2 (`tools_list …`, `tool_schema …`) |
| OpenCode | 1.19.5 | Docker `mcp-task-knowledge:cpu-cat-staging`, `✓ connected` | **не видит**: `NO_INSTRUCTIONS` на двух моделях; в `opencode export` нет строки `mcp-task-knowledge: 212 tools` |

Причина прежнего «`claude -p` зависает»: глобальный `~/.claude/settings.json` подменял
`ANTHROPIC_BASE_URL` на `https://opencode.ai/inference/go/anthropic` с `ANTHROPIC_AUTH_TOKEN`.
С чистым `CLAUDE_CONFIG_DIR` (только `.credentials.json`, без proxy env) Claude отвечает за
секунды. Это не дефект сервера, а конфигурация машины.

Вывод: `instructions` доходят до Claude Code, но **OpenCode 1.19.5 их не пробрасывает** в
контекст модели (при этом MCP-сервер connected). Для OpenCode нужен либо апстрим-фикс, либо
проектный скилл/AGENTS-подсказка; CM-06 нельзя закрывать как «instructions достаточно» для
всех клиентов.

## Почему

- Проба сделана на реальных CLI, не на SDK-моке.
- Claude-сессия была чистой: temp `CLAUDE_CONFIG_DIR`, пустой `mcpServers` в обычном тесте,
  затем только один сервер; без проектного скилла.
- OpenCode: `--pure`, temp cwd без `AGENTS.md`/`opencode.json`, глобальный MCP-сервер;
  две модели (`deepseek-v4.1-flash-free`, `minimax-m3.1-flash-free`) дали `NO_INSTRUCTIONS`.

## Проверено

- Claude clean: `claude -p 'Reply exactly OK'` → `OK`.
- Claude + MCP: ответ — шаг 1 `tools_list {search:"..."} to find a name`, шаг 2
  `tool_schema {name} for its input`.
- OpenCode `mcp list --pure`: `✓ mcp-task-knowledge connected` (Docker).
- OpenCode prompts на двух моделях → `NO_INSTRUCTIONS`; exported session не содержит
  строки `mcp-task-knowledge: 212 tools`.
- `backlog:check` — **429 total / 426 done / 0 pending / 2 counted blocked / 1 deferred**;
  CM-03b не входит в «Итого» (буквенный суффикс), фактически закрыт.

## Ограничения

- Один прогон на клиент/модель, не статистика; OpenCode 1.19.5, Claude 2.1.325.
- OpenCode-модели — free-тир; платные (claude-haiku) не проверялись (insufficient balance).
- Docker-образ `cpu-cat-staging` может отличаться от локального `dist`; для Claude
  использовался локальный сервер.
- Не проверялись другие клиенты (Cursor, Windsurf, VS Code) и OpenCode newer versions.
- Причина отсутствия instructions в OpenCode не локализована в коде OpenCode; зафиксирован
  факт и обходной путь (скилл/AGENTS) для CM-06.
