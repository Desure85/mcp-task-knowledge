# 2026-11-11 15:25 — TR-31: реальные health-пробы OAuth-коннекторов

- **Пункт:** TR-31 (medium), зависимость TR-03
- **Ветка / sha:** `feat/tr-31-oauth-health-probes`, от `origin/master` `43a1009`

## Вопрос

`gdrive/gmail/notion/onedrive/linear` считали `healthy: true`, если токен просто **есть**. Отозванный
или истёкший токен продолжал выглядеть здоровым, и `/readyz` не ловил деградацию.

## Решение

- `src/connectors/health-probe.ts` — `probeConnector(url, okMessage, {headers,method,body,timeoutMs})`:
  - один `fetch` с `connectorSignal()` (TR-33, 10 с по умолчанию);
  - `res.ok` → `{healthy:true, message}`;
  - HTTP-ошибка → `{healthy:false, message: 'HTTP <status> <body≤200>'}`;
  - сетевое исключение → `healthy:false`, не бросает.
- Пробы:
  - GDrive `GET /drive/v3/about?fields=user`;
  - Gmail `GET /gmail/v1/users/me/profile`;
  - Notion `GET /v1/users/me` + `Notion-Version: 2022-06-28`;
  - OneDrive `GET /graph.microsoft.com/v1.0/me/drive`;
  - Linear `POST /graphql` `{ viewer { id } }`.
- GDrive без OAuth access token теперь `healthy:false` даже при `apiKey`/`refreshToken`: эти поля не
  позволяют выполнить аутентифицированную пробу, и выдавать их за здоровье нельзя.

## Почему

- Самый дешёвый аутентифицированный read — единственный честный признак живого токена.
- Общий helper исключает пять копий обработки HTTP/сети и гарантирует единый timeout.
- Проба не меняет tool-контракт и не требует записи.

## Проверено

- `tests/connector-health-probes.test.ts` — **5/5**:
  - GDrive/Gmail/OneDrive — правильные URL и bearer-заголовки;
  - Notion version header; Linear POST/GraphQL body;
  - 401 → `healthy:false` с `401`;
  - network exception → `healthy:false`, не throw;
  - GDrive `apiKey`+`refreshToken` без access token → unhealthy.
- Существующие `connector-timeouts` + `real-apis` — **27/27**.
- **Мутация RED:** отключение проверки `res.ok` → 401-тест падает; восстановление 5/5.

## Ограничения

- Проба выполняется при каждом `health()`/`healthAll()`; кеша нет, поэтому частый `/readyz` даёт
  по одному внешнему запросу на коннектор.
- GDrive API-key-only режим не проверяется; refresh-token flow не обновляет токен.
- Тело ошибки обрезается до 200 символов.
- OAuth-коннекторы с иными auth-схемами (если появятся) требуют своей пробы.

## Откат

Revert ветки: удалить `health-probe.ts` и тест, вернуть `healthy:true` в пяти `health()` и импорты.
Внешние вызовы не меняются.
