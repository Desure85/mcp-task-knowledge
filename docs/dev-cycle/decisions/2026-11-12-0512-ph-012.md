## Вопрос

Нужны контрактные проверки GitHub/Jira/Slack без credentials и без новых зависимостей:
payload-маппинг и error-paths. DoD предлагает встроенный `undici` MockAgent.

## Решение

- `tests/connector-contract.test.ts` — 4 теста на реальных `create*Connector`:
  GitHub issue list (URL/state/per_page, Bearer, mapping, отсутствие body);
  Jira search (JQL `project = P AND status = "In Progress"`, `maxResults`, mapping);
  Slack channels/post (Bearer, JSON body, mapping); GitHub 403 и Slack `invalid_auth` → `{ok:false,error}`.
- Подмена — `vi.stubGlobal('fetch')`; **`undici` в дереве отсутствует** (`npm ls undici` → empty),
  поэтому MockAgent недоступен без новой devDependency. Fetch-стаб стоит на той же HTTP-границе,
  которую использует продовый код; nock/msw не добавлялись.

## Почему

- Контракт проверяет именно исходящий запрос и преобразование ответа, а не внутренние функции.
- Ноль новых зависимостей и ноль сетевых вызовов; тест детерминирован.
- Ошибки остаются конвертами, не throw.

## Ограничения

- Это не `undici` MockAgent из DoD: пакета нет, а добавлять зависимость запрещено. Тест мокает

- Проверены три коннектора; gdrive/gmail/notion/linear/onedrive не входят.
