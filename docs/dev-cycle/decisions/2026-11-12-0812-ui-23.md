# 2026-11-12 08:12 — UI-23: high-contrast palette

- **Пункт:** UI-23 (low)
- **Ветка / sha:** `feat/ui-23-high-contrast`, от `origin/master` `c990bbd`

## Вопрос

Нужна четвёртая палитра с контрастом основных пар ≥ 7:1 (AAA), отдельная от `data-mode`, без
нового пункта меню и без поломки AA-теста остальных палитр.

## Решение

- `app/globals.css`: два блока `[data-theme="high-contrast"][data-mode="light|dark"]` с тем же
  набором токенов; чистый чёрный/белый фон, усиленные границы, AAA-цвета текста.
- `lib/theme.ts`: `THEMES` дополнен `'high-contrast'` (появляется в общем списке и pre-paint).
- `lib/theme.contrast.test.ts`: AA-матрица теперь 94 пары × 8 вариантов; отдельный UI-23 тест
  проверяет 9 основных пар на ≥ 7:1 в обоих режимах.
- `e2e/high-contrast.spec.ts`: 12 маршрутов с `localStorage` high-contrast/dark, проверка
  `data-theme`/`data-mode` с первого paint (`domcontentloaded`).

## Почему

- Отдельный `data-theme` не смешивается с mode и не требует нового пункта меню.
- Токены те же, поэтому компоненты и утилиты не меняются.
- CSS — единственный источник палитры; тест парсит его, поэтому дрейф невозможен.

## Проверено

- `lib/theme.contrast.test.ts` — **4/4**, AA 94×8, AAA 9 пар × 2; высококонтрастный минимум:
  light 6.91 (не-core пары с порогом 3/4.5), dark 8.49.
- **Мутация RED:** `--accent: #0033cc` → `#777777`; 2 теста падают; восстановление 4/4.
- `lib/theme.test.ts` — **7/7**.
- `npm run test:types` (web-ui) — см. CI; e2e добавлен, но локально не запускался (нужен HTTP+логин).

## Ограничения

- Playwright-тест проверяет атрибуты и видимость `h1`, не пиксельный контраст и не «мигание»
  через кадры.
- AAA-проверка — 9 основных пар; статусные/типовые цвета остаются на AA (4.5/3), как в матрице.
- Палитра не добавляет отдельный пункт меню — только общий список тем.

## Откат

Удалить два CSS-блока, `'high-contrast'` из `THEMES`, UI-23 describe и e2e; остальные палитры
не затрагивались.
