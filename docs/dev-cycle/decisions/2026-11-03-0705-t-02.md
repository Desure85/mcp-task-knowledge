# 2026-11-03 07:05, T-02: ACL включён по умолчанию (подтверждено владельцем)

Решение владельца: ACL включать по умолчанию. Основание: после нового развёртывания в системе
только один админ, поэтому включение ничего не ломает. Пункт 3 записи 06:50 уточняется: «ACL по
умолчанию» больше не рекомендация контролёра, а решение владельца. Остаётся прежнее: при миграции
существующего развёртывания единственный env-админ становится admin всех проектов (обратная
совместимость), флаг выключения сохраняется; включение по умолчанию реализуется после T-01 (T-02
от него зависит). Откат: флаг выключения ACL.
