## Вопрос

Как подготовить `server.json` для official MCP registry, не имея доступа к реестру и не
выдавая локальную проверку за публикацию?

## Решение

- `server.json` (schema `2025-12-11`): `io.github.desure85/mcp-task-knowledge`, npm
  `mcp-task-knowledge@1.0.20`, stdio transport.
- `package.json`: `mcpName` = имя манифеста (требование ownership-проверки registry).
- `scripts/validate-server-json.mjs` + `npm run registry:validate`: offline-проверка schema URL,
  имени, description ≤100, semver, совпадения версий/пакета, `mcpName`, GitHub URL,
  npm/stdin.
- `docs/deployment/mcp-registry.md`: publish-команды и честные предпосылки; публикация **не
  выполнялась**.

## Почему

- Публикация требует `mcp-publisher`, GitHub-логина и владения namespace; этого в среде нет.
- Проверка идентичности без сети ловит типичный дрейф версии/имени и не создаёт ложного
  «опубликовано».
- `mcpName` в package.json — аддитивное поле; текущий npm-таббл 1.0.20 его не содержит, поэтому
  перед реальной публикацией нужен новый патч-релиз.
