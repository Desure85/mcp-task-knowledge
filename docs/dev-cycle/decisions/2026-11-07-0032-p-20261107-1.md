# 2026-11-07 00:32, P-20261107-1: журнал решений — файл на решение

Вопрос: как убрать конфликт параллельных PR по единственному append-only `docs/dev-cycle/decisions-log.md`,
не меняя структуру `BACKLOG.md` и сохранив существующие записи и ссылки на них.

Решение: журнал разделён на файлы `docs/dev-cycle/decisions/YYYY-MM-DD-HHMM-<id-slug>.md` — 24 записи
из `538a6d4`, по одной на файл. Преамбула журнала перенесена в `decisions/README.md` дословно;
`decisions-log.md` стал указателем на четыре строки. `probeDecisions` читает каталог (сортировка по
имени, последние N, README пропускается), старый путь оставлен запасным при отсутствии каталога.
Ссылки перепривязаны к файлам: `:96-101` → `2026-11-03-0650-tk-01.md`,
`:120-141`/`:128-133`/`:133` → `2026-11-03-0720-y-09.md`. Новые записи создаются файлом с реальным
временем `HHMM`; исторические записи без времени получили синтетический ключ `0001…` по порядку
внутри даты.

Почему: конфликт снимается по построению — каждый PR меняет свой файл. Решения ревьюируются по
отдельности, а «последние N» остаются детерминированными: имя начинается с даты и единого
4-значного ключа времени, поэтому сортировка по имени совпадает с хронологией. Указатель сохраняет
старые ссылки, преамбула не теряется.

Проверено: 24/24 тел файлов побайтно равны исходнику, sha256 конкатенации тел
`c9a9a5f48b2a01228db7a3b7a81fcf8ca245ed962ec02b1d3f28c76d7b644895` до и после; sort(имён) равен
порядку исходника. `npx vitest run tests/devcycle-probe.test.mjs` — 8 passed; revert-check: без
чтения каталога 3 failed, запись с заголовком `###` в указателе — 1 failed. `node scripts/devcycle.mjs status`
и `report` читают каталог: «последние 3» — 2026-11-07 00:30, 2026-11-06 23:50, 23:43. Полный
`npm test` — 271 файл, 3124 теста, зелёные; `npm run build`, `test:types`, `lint`, `lint:md`,
`backlog:check` — код 0.

Откат: revert PR. Монолит восстанавливается из истории:
`git show 538a6d4:docs/dev-cycle/decisions-log.md > docs/dev-cycle/decisions-log.md` и удаление
каталога `docs/dev-cycle/decisions/`.
