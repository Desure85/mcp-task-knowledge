# 2026-11-13 22:20 — DX-21: Homebrew/Scoop generator (mock v1)

- **Пункт:** DX-21 (low, был `blocked` по DX-20)
- **Ветка:** `feat/dx-21-package-managers`, от `origin/master` `67c4d11`
- **Разрешение владельца:** «мок» — генератор и проверки без реального release CI.

## Вопрос

DX-20 дал Windows PoC-бинарь, но DX-21 требует Homebrew formula и Scoop manifest «в release
CI». Реального release pipeline и macOS/Linux-артефактов нет. Что можно закрыть честно?

## Решение

- `scripts/gen-package-managers.mjs` — offline-генератор из descriptor:
  `version`, `repository`, `description`, `license`, `assets[platform] = { url, sha256 }`.
- Выход: `mcp-task-knowledge.rb` (macOS arm64/x64, Linux arm64/x64) и
  `mcp-task-knowledge.json` (Scoop, Windows x64).
- Валидация: semver, GitHub HTTPS, SHA-256 (64 lowercase hex), HTTPS URL, парность
  darwin/linux-архитектур, обязательный `win-x64`, неизвестные ключи.
- `npm run packages:generate`; docs `docs/deployment/package-managers.md`.
- В release CI **не встроено**: нет артефактов и пайплайна; это зафиксировано.

## Почему

- Генератор — единственная часть DX-21, которую можно проверить без релиза; он детерминирован
  и не требует сети.
- Требование парности архитектур не даёт выпустить формулу с пустым URL/хэшем.
- Scoop-манифест требует `win-x64`; без него генерация падает, а не создаёт битый манифест.

## Проверено

  Scoop JSON/hash, плохие sha/URL/парность, отсутствие Windows/неизвестный ключ.
- Revert-check: отключение проверки SHA-256 → RED, восстановление 5/5.
- CLI вручную: descriptor → оба файла в `dist-packages`.
- `backlog:check` — **429 total / 424 done / 0 pending / 4 blocked / 1 deferred**.

## Ограничения

- **Release CI не подключён**, реальных артефактов macOS/Linux/Windows нет; DX-20 дал только
  Windows PoC.
- `brew audit`/`brew install` и `scoop install` не запускались.
- Нет autoupdate/checkver, tap-репозитория, подписи/нотаризации и checksums-файла.
- Версия берётся из descriptor, а не из `package.json`; `0.0.0` в бинаре DX-20 не исправлен.
