## Вопрос

Консолидировать незавершённые драфты в факты/паттерны по событию, без дублей при повторном прогоне, и отправить событие синка один раз.

## Решение

- `src/drafts/consolidate.ts`: `consolidateDrafts(root)` читает pending drafts, добавляет строки `- [draft:<key>] <title>` в `facts.md`, паттерны в `patterns.json`, пишет `sync-events.jsonl` только если его ещё нет, затем ack всех драфтов.
- Повторный вызов на пустом журнале: `facts=0`, `eventEmitted=false`.

## Почему

- Draft journal append-only и ack уже есть; консолидация не дублирует записи по ключу `draft:<key>`.
- Файлы facts/patterns — простые, без миграции схемы.

## Проверено

- `tests/draft-consolidation-event.test.ts` — **1/1**: 2 драфта → 2 факта/паттерна, одно событие, повторный прогон без дублей и без второго события.
- build чистый; `backlog:check` **390/0/30/1**.

## Ограничения

- Нет MCP-инструмента/UI и автоматического триггера «конец сессии» — вызывается кодом.
- `memory:verify --limit 50` на этих facts.md не прогонялся: это отдельные файлы, не temporal facts.
- Паттерны не агрегируются (count=1), без семантической кластеризации.
