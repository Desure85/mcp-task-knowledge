## Вопрос

Нужны дальнейшие источники промптов/скиллов через `PromptSource` и отчёт о лицензиях.
Живые API awesome-списков/реестра MCP и Hugging Face/LangChain Hub недоступны без сети/лицензионной
проверки; нужен безопасный локальный снимок.

## Решение

- `McpRegistrySource` (в `src/prompts/sources.ts`): читает локальный снимок реестра
  (`server.json`/`{servers:[]}`), отдаёт `list/preview/import`, хранит `license`, `homepage`/`repository`.
- `AwesomeListSource`: читает локальный клон awesome-списка (`README.md`/`awesome.md`), парсит
  `- [Title](url) — description`, дедуплицирует id, берёт лицензию из `LICENSE`/`LICENSE.md`/`COPYING`.
- `PromptSourceItem` получил аддитивные `url` и `license`; `PromptSourceLicenseReport` —
  `source`, `sourceLicense`, `items[{id,title,url,license}]`.
- Импорт пишет markdown-заглушку с источником и лицензией; сами связанные ресурсы не скачиваются.
- Ядро не менялось — только слой источников.

## Почему

- Локальный снимок воспроизводим, не зависит от rate limit и не тянет чужие лицензии автоматически.
- Отчёт о лицензии делает происхождение явным до импорта.
- `PromptSource` остаётся единственным контрактом; новые источники не требуют правок ядра.
