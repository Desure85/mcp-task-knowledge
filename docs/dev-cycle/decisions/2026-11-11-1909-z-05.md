# 2026-11-11 19:09 — Z-05: источник промптов и скиллов

- **Пункт:** Z-05 (medium), зависит от Z-02, Z-04, INT-004
- **Ветка / sha:** `feat/z-05-prompt-sources`, от `origin/master` `dfa6610`

## Вопрос

Библиотека промптов/скиллов умела хранить и собирать локальные записи, но не умела смотреть
наружу: не было единого интерфейса «каталог → поиск → preview → import», локального
Claude Code marketplace и GitHub-репозитория по ссылке.

## Решение

- `src/prompts/sources.ts`:
  - `PromptSource` с `list(query)`, `preview(id)`, `import(id,targetDir,{overwrite})`;
  - `PromptSourceItem`/`PromptSourcePreview`/`PromptImportResult`;
  - `LocalMarketplaceSource`: `.claude-plugin/marketplace.json` или `marketplace.json`,
    `plugins[]` с `name/description/version/source`; файл или каталог (`SKILL.md`, `PROMPT.md`,
    `README.md`, `<name>.md|json`); fallback-скан без манифеста;
  - `GitHubPromptSource`: GitHub tree API + raw URLs, `repo/ref/token/fetchImpl/apiBase/rawBase`;
  - `PromptSourceError` с кодами `NOT_FOUND|INVALID_SOURCE|PATH_ESCAPE|TOO_LARGE`, лимит 2 MiB;
  - import пишет `<basename>.<ext>` через `wx`, `overwrite` — явный флаг.
- `docs/features/prompt-sources.md`.
- MCP-инструменты/UI не добавлялись: это слой источников, следующий шаг может подключить его к
  `prompts_*`/`skills_*`.

## Почему

- Единый интерфейс отделяет транспорт (локальный каталог, GitHub) от импорта и позволяет
  тестировать оба источника с `fetchImpl`/temp-каталогом.
- Marketplace-манифест — точка правды Claude Code; fallback-скан полезен для простых каталогов.
- Двойная проверка пути (lexical + realpath) закрывает symlink-побег, который лексическая
  проверка не видит.
- `wx` по умолчанию: импорт не затирает существующий файл без явного решения.

## Проверено

- `tests/prompt-sources.test.ts` — **6/6**:
  - marketplace: список/фильтр, preview, import, повтор без `overwrite` → ошибка, с `overwrite` — успех;
  - unknown id → `NOT_FOUND`; `source: '../evil'` → `PATH_ESCAPE`;
  - GitHub fixture: tree/raw, фильтр по `prompts/`+`skills/`, Bearer, preview, import;
  - 500 tree → `INVALID_SOURCE`, 404 raw → `NOT_FOUND`, `repo` без `owner/name` → ошибка.
- build/tsc.
- **Мутация RED:** `assertInside` → no-op; тест `PATH_ESCAPE` падает; восстановление 6/6.

## Ограничения

- Нет MCP-инструментов и UI: источник нельзя вызвать из агента/веба без кода.
- Marketplace `source` обязан быть путём; URL/git-источники плагинов не разрешаются.
- GitHub: без токена действует rate limit; recursive tree API имеет лимит; нет ZIP-fallback;
  title берётся из имени файла, метаданные манифеста не читаются.
- Import копирует сырой документ, не парсит его в `PromptDraft`/skill package и не создаёт версию.
- `realpath`-проверка пропускает nonexistent source (становится «нет plugin»), а не даёт
  детальную ошибку.
- Лимит 2 MiB на документ, без потоковой загрузки.
- Дедупликация id между плагинами не делается (последний/первый по обходу).

## Откат

Удалить `src/prompts/sources.ts`, тест и docs/решение; ничего в существующих prompt/skill путях не
менялось.
