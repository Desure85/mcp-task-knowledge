# 2026-11-13 22:00 — INT-008: двусторонняя синхронизация задач (mock v1)

- **Пункт:** INT-008 (medium, был `blocked` по записываемому YouTrack)
- **Ветка:** `feat/int-008-sync`, от `origin/master` `c326ee8`
- **Разрешение владельца:** «мок» — live YouTrack не требуется, но подмена не выдаётся за live.

## Вопрос

Как проверить циклическую двустороннюю синхронизацию, идемпотентность, внешний id и
конфликты поверх MU-02, не имея записываемого доступа к YouTrack?

## Решение

- `Task.external = { system, id, url?, updatedAt?, localHash? }` — аддитивное поле.
- `src/sync/engine.ts`: один цикл `pull/push/both`; локальные изменения определяются хешем
 маппинг-полей, внешние — `updatedAt` трекера; второй цикл — `skipped`, дублей нет.
- Конфликты: обе стороны менялись, timestamps равны, поля расходятся → `conflicts[]`;
  более свежая сторона побеждает; dry-run ничего не пишет.
- `src/sync/file-tracker.ts` — JSON-адаптер `$DATA_DIR/sync/<project>.json` (mock-трекер).
- `tasks_sync` — MCP-инструмент; `system=file` работает, `system=youtrack` честно возвращает
  `SYNC_NOT_CONFIGURED`; `dryRun=true` по умолчанию, запись только с `confirm:true`.
- `DEFAULT_MAPPING` статусов/приоритетов с валидацией дублей/пустых значений.

## Почему

- Хеш локальных полей, а не `updatedAt`: запись `external` сама бампает `updatedAt`, иначе
  второй цикл всегда выглядел бы грязным.
- Один цикл без фонового цикла и без рекурсии — зацикливание невозможно по конструкции.
- File adapter даёт воспроизводимый e2e-контракт без токена; YouTrack write-side оставлен
  явным TODO, а не имитацией.

## Ограничения

- **Live YouTrack/Jira/Linear не проверялись**; write-side YouTrack-адаптера нет.
- Конфликт определяется по набору маппинг-полей, не по каждому полю отдельно; сравнение
  «свежести» — по task-level `updatedAt`.
- Нет фоновой/периодической синхронизации, пагинации больших трекеров, удаления и UI.
- File adapter — однопроцессный JSON без lock; это mock, не durable tracker.
- `system=youtrack` в tool всегда `SYNC_NOT_CONFIGURED`; это осознанная заглушка.
