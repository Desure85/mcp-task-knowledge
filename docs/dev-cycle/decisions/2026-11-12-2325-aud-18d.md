## Вопрос

EventLog переписывает весь лог на каждый append; `compactThreshold` не используется — лог растёт неограниченно.

## Решение

`append()` после push проверяет `events.length >= compactThreshold` и вызывает существующий `compact()`;
иначе — обычный persist. Порог по умолчанию 1000; тест с порогом 3 проверяет авто-компакцию,
snapshot последнего состояния и `eventCount=0`.

## Почему

- Не нужно переписывать механику: `compact()` уже создаёт snapshots и GC-ит события.
- Достаточно подключить существующий порог; wire-формат и API не меняются.
- Для мёртвого sync-стека (AUD-18e) это не притворяется «починкой всего»: только ограничение роста.

## Проверено

- `src/sync/event-log.spec.ts` — **9/9** (8 старых + новый auto-compact).
- build чистый; тест на порог 3: после 3-го append `eventCount=0`, snapshot `v3`.
- `backlog:check` **398/0/22/1** (AUD-18d — подпункт вне «Итого»).

## Ограничения

- `persist()` всё ещё сериализует весь лог; append-only JSONL не сделан.
- Sync-стек остаётся мёртвым (AUD-18e) — Auto-compact не делает его подключённым.
- Нет нагрузочного теста на тысячи append.

## Откат

Убрать вызов `compact()` из `append()`, вернуть безусловный `persist()`; тест удалить.
